# Corvix Shell — 안드로이드 SSH 터미널

**Corvix Shell**은 안드로이드에서 SSH 서버에 접속하는 터미널 클라이언트입니다.
접속 정보와 인증 수단을 **기기 내부에만 암호화 저장**하고, 개발자 서버나 중계 서버 없이
사용자가 지정한 서버에 **직접 연결**합니다.

- 패키지명: `io.acusworks.corvix`
- 플랫폼: Android
- 배포: Google Play (출시 준비 중)
- [개인정보처리방침 / Privacy Policy](/corvix-shell/privacy/)

---

## 기기에만 남습니다

접속 정보(호스트, 포트, 사용자 이름)와 인증 수단(비밀번호, SSH 개인키, 키 암호구문)은
기기 내부 저장소에 암호화되어 보관됩니다. 개발자가 운영하는 서버가 없고, 클라우드 동기화나
계정 백업 기능도 없습니다. 저장된 정보는 이 기기를 벗어나지 않습니다.

## 직접 연결

중계 서버를 거치지 않고 사용자가 지정한 SSH 서버에 바로 연결합니다. 통신 내용은 SSH
프로토콜로 암호화되며, 개발자는 접속 대상 서버나 터미널에서 오간 내용에 접근할 수 없습니다.

## 가져오기 · 내보내기

- **개인키 가져오기** — 시스템 파일 선택 화면에서 고른 키 파일만 읽습니다.
- **접속 정보 내보내기** — 저장한 접속 정보를 파일로 내보냅니다. 사용자가 직접 실행할 때만
  동작하며, 파일은 사용자가 고른 위치에 저장됩니다.

> 내보낸 파일에는 인증 정보가 포함될 수 있습니다. 안전한 위치에 보관하시고 불필요해지면
> 삭제하시기 바랍니다.

## 계정 불필요

회원가입이나 로그인 없이 바로 사용할 수 있습니다. 광고, 사용 분석, 크래시 리포트 등
제3자 SDK를 포함하지 않습니다.

---

## 앱이 사용하는 권한

| 권한 | 용도 |
|---|---|
| 인터넷 | 사용자가 지정한 SSH 서버 접속 |
| 파일 선택 | 개인키 가져오기 · 접속 정보 내보내기 시, 시스템 파일 선택 화면에서 직접 고른 파일에만 접근 |

기기 내 다른 파일이나 저장소 전체에 접근하는 권한은 요청하지 않습니다.

## 데이터 삭제

앱이 저장한 모든 정보는 앱 안에서 개별 삭제할 수 있으며, 앱을 삭제하면 함께 완전히
삭제됩니다. 개발자 측에는 삭제를 요청할 데이터가 존재하지 않습니다.
