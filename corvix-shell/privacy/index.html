Corvix Shell 개인정보처리방침

시행일: 2026년 9월 13일 · 최종 수정일: 2026년 9월 13일

Corvix Shell(패키지명 io.acusworks.corvix, 이하 "본 앱")은 안드로이드 기기에서 SSH 서버에 접속하기 위한 터미널 클라이언트입니다. 본 방침은 본 앱이 정보를 어떻게 다루는지 설명합니다.

1. 개발자가 수집하는 정보

없습니다. 본 앱은 개인정보를 포함한 어떠한 정보도 수집·전송하지 않으며, 개발자가 운영하는 서버는 존재하지 않습니다. 개발자는 사용자의 접속 정보, 접속 대상 서버, 터미널에서 오간 내용 중 어느 것에도 접근할 수 없습니다.

2. 기기 내부에 저장되는 정보

사용자가 직접 입력한 다음 정보가 기기 내부 저장소에만 보관됩니다.

  • 호스트 주소, 포트, 사용자 이름
  • 인증 정보 — 비밀번호, SSH 개인키, 키 암호구문
  • 알려진 호스트 키(known hosts), 접속 이력 및 앱 설정

인증 정보는 암호화된 형태로 저장되며, 외부로 전송되지 않습니다. 이 정보는 사용자의 기기를 벗어나지 않습니다.

3. 네트워크 통신

본 앱의 네트워크 통신은 사용자가 직접 지정한 SSH 서버와의 직접 연결이 전부입니다. 개발자의 서버나 제3자의 중계 서버를 경유하지 않으며, 통신 내용은 SSH 프로토콜로 암호화됩니다.

접속 대상 서버가 어떤 정보를 기록하는지는 해당 서버 운영자의 정책에 따르며, 본 방침의 적용 범위 밖입니다.

4. 내보내기(Export) 기능

본 앱은 사용자가 저장한 접속 정보를 파일로 내보내는 기능을 제공합니다. 이 기능은 사용자가 직접 실행할 때만 동작하며, 생성된 파일은 사용자가 지정한 위치에 저장됩니다. 개발자는 이 파일에 접근할 수 없습니다.

주의 — 내보낸 파일에는 인증 정보가 포함될 수 있습니다. 파일의 보관·전달·삭제에 대한 책임은 사용자에게 있으므로, 안전한 위치에 보관하시고 불필요해지면 삭제하시기 바랍니다.

5. 온라인 동기화

본 앱은 클라우드 동기화, 계정 백업, 기기 간 동기화 기능을 제공하지 않습니다. 저장된 정보는 해당 기기에만 존재합니다.

6. 제3자 제공 및 광고

본 앱은 광고 네트워크, 사용 분석 도구, 크래시 리포트 도구를 비롯한 어떠한 제3자 SDK도 포함하지 않으며, 어떠한 정보도 제3자에게 제공하거나 판매하지 않습니다.

7. 앱이 사용하는 권한

  • 인터넷 — 사용자가 지정한 SSH 서버에 접속하기 위해 사용됩니다.
  • 파일 선택 — 개인키 가져오기 및 접속 정보 내보내기 시, 사용자가 시스템 파일 선택 화면에서 직접 고른 파일에만 접근합니다. 기기 내 다른 파일에는 접근하지 않습니다.

8. 데이터 보관 및 삭제

본 앱이 저장한 모든 정보는 앱 내에서 개별 삭제할 수 있으며, 앱을 삭제하면 함께 완전히 삭제됩니다. 개발자 측에 삭제를 요청할 대상 데이터는 애초에 존재하지 않습니다.

9. 아동의 개인정보

본 앱은 개발자 및 시스템 관리자를 위한 도구이며, 모든 사용자로부터 개인정보를 수집하지 않습니다.

10. 방침의 변경

본 방침이 변경될 경우 이 페이지에 변경된 내용과 시행일을 게시합니다.

Privacy Policy for Corvix Shell

Effective: September 13, 2026 · Last updated: September 13, 2026

Corvix Shell (package io.acusworks.corvix, the "App") is a terminal client for connecting to SSH servers from an Android device. This policy explains how the App handles information.

1. Information Collected by the Developer

None. The App collects and transmits no information of any kind, and the developer operates no server. The developer has no access to your connection details, the servers you connect to, or anything exchanged in your terminal sessions.

2. Information Stored on Your Device

The following, entered by you, is stored solely within your device:

  • Host address, port, and username
  • Credentials — passwords, SSH private keys, and key passphrases
  • Known host keys, connection history, and app settings

Credentials are stored in encrypted form and are never transmitted. This information does not leave your device.

3. Network Communication

The App's only network activity is a direct connection to the SSH server you specify. No developer server or third-party relay is involved, and the connection is encrypted by the SSH protocol.

What a destination server logs is governed by that server operator's policy and falls outside the scope of this policy.

4. Export Feature

The App can export your saved connection entries to a file. This runs only when you initiate it, and the resulting file is written to a location you choose. The developer cannot access this file.

Note — An exported file may contain credentials. Storing, transferring, and deleting it is your responsibility; keep it somewhere safe and delete it when it is no longer needed.

5. Online Synchronization

The App provides no cloud sync, account backup, or cross-device synchronization. Stored information exists only on the device where it was entered.

6. Third Parties and Advertising

The App contains no advertising networks, analytics tools, crash reporting tools, or any other third-party SDK, and shares or sells no information to anyone.

7. Permissions Used

  • Internet — used to reach the SSH server you specify.
  • File selection — when importing a private key or exporting connection entries, the App accesses only the file you pick in the system file picker. It does not access other files on your device.

8. Retention and Deletion

Anything the App stores can be deleted individually within the App, and is removed entirely when the App is uninstalled. There is no developer-held data to request deletion of.

9. Children's Privacy

The App is a tool for developers and system administrators and collects no personal information from any user.

10. Changes to This Policy

Any changes will be posted on this page together with their effective date.
